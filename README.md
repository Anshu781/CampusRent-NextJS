# CampusRent — Next.js + Lenis

A responsive, student-to-student campus rental marketplace concept built with Next.js App Router, React, Lucide icons, and Lenis smooth scrolling.

## Run locally

Requires Node.js 18.18+ (Node 20+ recommended).

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included

- Responsive landing page and item cards
- Search, category filtering, hostel/block filtering
- Sample inventory: kettle, iron, calculator, cycle, lamp, speaker, extension board, badminton set
- Campus location choices: Kalam A/B/C/D, Aryabhatta A/B/C/D, CV Raman, Married Accommodation, Ashima, and an entire-hostel option
- Save/favourite interactions
- Lenis smooth scrolling
- Demo toast messages for rent/list actions
- Metadata and copyright footer

## Before publishing

This is an HS project concept demo. Listings, prices, ratings, and owners are sample data. The rent and list actions are placeholders, not a real booking or payment system. Before production, add authentication, real listing storage/database, owner contact flow, availability dates, rental terms, moderation, and payment/security handling. Confirm official hostel/location names and campus policies before launch.
